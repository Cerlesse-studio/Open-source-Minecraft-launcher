把启动器
还给玩家。

Open-source-Minecraft-launcher 是一个由玩家和开发者共同维护的开源项目。我们想把启动这件小事做得干净、稳定、可掌控，然后把时间还给游戏本身。

v0.0.7 MIT License Open Source Windows 10 / 11
WHY THIS PROJECT

不是又一个套壳启动器。

很多启动器把「能启动」当成终点，却把版本、Java、下载源、模组冲突和联机留给了用户。我们选择另一条路：把容易出错的环节下沉到 Rust 后端，让界面只负责清晰地呈现状态和选择。

启动器同时支持 Java 版与基岩版，内置 EasyTier 联机、Modrinth / CurseForge 内容搜索、微软与离线账户、自动 Java 管理与镜像容灾下载。它不包含广告或遥测，账户令牌只保存在本机。

项目以 MIT 协议开源。你可以查看每一行代码、自行构建，或者把它改成更适合自己的样子。

PRINCIPLES

我们相信的四件事。

开源透明

代码、构建方式与第三方声明全部公开。启动器不应该是一个无法检查的黑盒。

本地优先

账户令牌、下载断点与游戏数据默认留在本机。没有广告，也没有不必要的遥测。

体验优先

下载要稳、启动要快、错误要说人话。复杂逻辑留在后端，界面保持清晰。

双版本统一

Java 版与基岩版不应该被迫使用两套完全不同的工具。版本、账户与内容可以在一个地方管理。

ONGOING

发布与平台验证

完善预编译产物、Windows 之外的 Java 版验证，以及文档、错误提示与边界情况。

LONG TERM

更稳定的日常工具

继续打磨下载、兼容性与可维护性，让启动器成为长期可用的基础设施，而不是一次性项目。

TECH

技术选型。

使用系统 WebView 而不是自带 Chromium；下载、解包、校验、启动与 EasyTier 进程都在 Rust 侧完成。前端只负责呈现状态与下发命令。
