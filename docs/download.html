BUILD FROM SOURCE

从源码构建

需要 Node.js、Rust 与 Tauri 2 的系统依赖。首次构建会编译全部 Rust 依赖，耗时较长。

bash
git clone https://github.com/Cerlesse-studio/Open-source-Minecraft-launcher.git
cd Open-source-Minecraft-launcher
npm install
npm run tauri build
完整构建文档 查看系统要求

构建产物：src-tauri/target/release/bundle/。Windows 通常生成 MSI / NSIS，macOS 生成 DMG，Linux 生成 deb / AppImage。

REQUIREMENTS

开始之前

运行预编译版本与源码构建的要求不同；基岩版和联机还有额外的系统条件。

Windows 10 / 11 x64 完整功能平台。预编译版本需要 WebView2；Windows 10 / 11 通常已内置。
Node.js + Rust 源码构建需要 Node.js 20.19+ / 22.12+ 与 Rust stable 1.85+，并安装 Tauri 2 系统依赖。
网络与联机 首次安装版本、依赖与 Java 需要联网；EasyTier 联机需要双方都有公网 IPv6。
AFTER LAUNCH

安装之后，先做这三件事。

01

确认游戏目录

默认是 ~/.cobble。想放在其他磁盘，可以在设置里更换根目录。

02

登录或使用离线账户

微软账户用于正版会话与基岩版授权检测；离线账户适合单人与离线服务器。

03

下载第一个版本

进入下载中心选择 Java 或基岩版；Java 版可以顺便配置 Forge / Fabric 等加载器。

DOWNLOAD FAQ

下载常见问题

为什么 Releases 里没有安装包？

项目仍在快速迭代，预编译产物尚未稳定发布。可以先按源码构建；Release 发布后，本页与 GitHub Releases 会提供对应平台的安装包。

Windows 提示「未知发布者」怎么办？

当前构建可能没有代码签名，SmartScreen 会提示未知发布者。请核对下载来源，或从源码自行构建；不要通过第三方链接绕过安全检查。

macOS / Linux 有安装包吗？

目前以源码构建为主。Java 版可以尝试在 macOS / Linux 构建运行；基岩版、Xbox 运行时、winget 与 Windows 防火墙集成仅限 Windows。

构建时提示找不到 Rust 或 Cargo？

先安装 Rust stable，并确认 cargo --version 可用。Tauri 还需要对应平台的系统依赖，详见 环境要求。
