FEATURES

基础功能，一处完成。

版本、账户、下载、模组与联机都在启动器内处理，不需要额外工具。

技术概览

Java 与基岩版

Java 正式版、快照、愚人节与远古版本共用版本库；Windows 基岩版、Linux BDS 与 macOS MCPELauncher 分平台覆盖。

账户与皮肤

微软 OAuth 与离线账户并存，支持正版皮肤、离线皮肤包与基岩版授权检测。

下载与镜像

1–64 线程分片、断点续传、SHA-1 校验，支持官方源、BMCLAPI 与自定义镜像。

加载器与内容

Forge、NeoForge、Fabric、Quilt、OptiFine；Modrinth 与 CurseForge 的模组、光影、资源包、数据包、Java / 基岩版地图与整合包。

联机双模式

默认纯 IPv6 P2P 直连，不经过 STUN / 信令 / 中继；没有公网 IPv6 时可切换公益节点，由协助节点打洞与多线路中继。

实例与个性化

每个版本独立内存、JVM 参数与隔离；可设置图标、分类、别名、描述与收藏，并支持主题、壁纸、字体与 PCL2 主页。

下载引擎文档

0.1.7

下载引擎重做 · 文字与排版修复

最新

更新内容

  • 下载引擎对齐 PCL2 语义：全局线程上限、令牌桶限速与分片看门狗；客户端、依赖库、资源、加载器与安装器共用同一套多线程策略。
  • 断点续传：分片布局与已完成分片写入 .part.meta，重启启动器或切换镜像只补缺失分片。
  • 设置新增全局下载限速（MB/s，0 为不限速），对分片下载、单流下载与断点续传统一生效。
  • 下载源优先级整理：Java 版本清单与游戏本体优先官方 CDN，失败后按镜像链回退，并可在设置里查看每个源的说明。
  • 内容市场统一检索：模组、整合包、数据包、光影、资源包与地图共用同一套类型、分页与筛选规则。
  • 联机：P2P 连接健康检查与公共节点发现，切换中继后房间仍能互相发现。

修复的 Bug

  • 开启系统代理后下载速度掉到直连的五分之一：下载改走独立的直连客户端，只有连接层失败时才回退系统代理。
  • 部分文字不显示：font-mono 与 font-pixel 字体栈缺少中文字体回退，徽标、版本号与像素标题里的中文会整段空白。
  • 侧栏底部的「空闲」被挤成一字一行的竖排，启动器版本号被折断成两行。
  • 右栏底部统计（Java 版本 / 基岩版 / 附加包）在窄窗口被裁掉，现在会自动换行。
  • 新闻卡版本号在连字符处折行（26.4-snapsho / p-7）。
  • 旧渲染器（Chromium 108）把 bg-gold/10 降级成实心金色，金色徽标文字与底色重合而看不见；透明度改用显式 rgba 回退。

0.1.6

外置登录 · 账户与安装流程

稳定版

更新内容

  • 新增 LittleSkin 外置登录（Yggdrasil），与微软账户、离线账户并列，可切换档案与皮肤。
  • 账户对话框重做：登录方式、账户档案与皮肤入口集中在同一处，不再分散在多个面板。
  • 版本安装与启动编排整理：Java 版版本清单与本体优先走官方 CDN，失败后自动回退镜像源。
  • 加载器流程统一：Forge / NeoForge / Fabric / Quilt 的依赖库与安装器共用同一套镜像链。
  • 联机房间资源清单完善：访客按房主的版本与资源一键补齐模组、光影与数据包。

修复的 Bug

  • Quilt 加载器的库此前没有任何镜像回退，官方源一慢就只能干等，现在会回退到 BMCLAPI。
  • Java 版单连接下载没有停滞检测：一个卡住的小文件会占住 worker 直到 600 秒全局超时，现在 30 秒收不到字节就重试或换源。
  • 下载速度显示在停顿帧会突然跳回全局平均值，造成数字忽高忽低，改为指数移动平均平滑。

立即下载体验
GET STARTED

三步开始游戏。

下载版本、选择账户、启动；Java 缺失时会自动安装。

STEP 01

下载版本

在下载页选择 Java 或基岩版；需要模组时选择 Forge、NeoForge、Fabric 或 Quilt。

STEP 02

配置账户与 Java

登录微软账户或使用离线昵称；Java 会自动匹配，缺失时安装 Temurin JRE。

STEP 03

启动或联机

一键进入游戏。需要联机时在联机页创建房间，把分享码发给好友。

BUILT ON

界面轻量，核心在 Rust。

下载、解包、校验、启动编排与 EasyTier 进程都由 Rust 完成，React 只负责呈现状态，切换页面不会中断下载任务。
