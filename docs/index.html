FEATURES

基础功能，一处完成。

版本、账户、下载、模组与联机都在启动器内处理，不需要额外工具。

技术概览

Java 与基岩版

Java 正式版、快照、愚人节与远古版本共用版本库；Windows 基岩版、Linux BDS 与 macOS MCPELauncher 分平台覆盖。

账户与皮肤

微软 OAuth 与离线账户并存，支持正版皮肤、离线皮肤包与基岩版授权检测。

下载与镜像

1–64 线程分片、断点续传、SHA-1 校验，支持官方源、BMCLAPI 与自定义镜像。

加载器与内容

Forge、NeoForge、Fabric、Quilt、OptiFine；Modrinth 与 CurseForge 的模组、光影、资源包、数据包、Java / 基岩版地图与整合包。

联机双模式

默认纯 IPv6 P2P 直连，不经过 STUN / 信令 / 中继；没有公网 IPv6 时可切换公益节点，由协助节点打洞与多线路中继。

实例与个性化

每个版本独立内存、JVM 参数与隔离；可设置图标、分类、别名、描述与收藏，并支持主题、壁纸、字体与 PCL2 主页。

立即下载体验
GET STARTED

三步开始游戏。

下载版本、选择账户、启动；Java 缺失时会自动安装。

STEP 01

下载版本

在下载页选择 Java 或基岩版；需要模组时选择 Forge、NeoForge、Fabric 或 Quilt。

STEP 02

配置账户与 Java

登录微软账户或使用离线昵称；Java 会自动匹配，缺失时安装 Temurin JRE。

STEP 03

启动或联机

一键进入游戏。需要联机时在联机页创建房间，把分享码发给好友。

BUILT ON

界面轻量，核心在 Rust。

下载、解包、校验、启动编排与 EasyTier 进程都由 Rust 完成，React 只负责呈现状态，切换页面不会中断下载任务。
