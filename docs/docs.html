01概览

Open-source-Minecraft-launcher 是一个基于 Electron 的桌面 Minecraft 启动器：前端使用 React 19 + TypeScript，后端使用 Rust 2024。界面通过 Electron IPC 调用后端能力，下载、解包、校验、启动与 EasyTier 进程都由 Rust 持有。

Windows 10 / 11 提供最完整的基岩版路径与系统集成；Linux 额外支持 Mojang 官方 bin-linux BDS 服务端，EasyTier 联机在 macOS / Linux 上以无 TUN、无管理员权限的方式运行；macOS 以 Java 版和已安装的 MCPELauncher 客户端为主，没有官方基岩版运行时。

0.1.4 增加了可扩展的运行时：原生 JavaScript + Rust/WASM 扩展、Chrome Manifest V2 / V3 兼容扩展、中英双语界面、纯 IPv6 P2P / 公益节点双模式，以及基于 GitHub Releases 的 OTA 更新。

双版本Java 版与基岩版共用一套版本库与启动入口。
原生后端下载、安装、启动、账户、联机都在 Rust 侧完成。
可扩展Chrome MV2/MV3 兼容与原生 Rust/WASM 扩展系统。
可更新GitHub Releases 检查、下载与平台化安装。
本地优先账户令牌、下载断点与游戏数据默认保存在本机。
可替换内容源、下载源、Java、主题与主页都可以自行配置。

02环境要求

运行预编译版本与从源码构建的要求不同。预编译版本需要 Electron 支持的系统环境和网络；源码构建还需要 Node.js 与 Rust 工具链。

项目要求
操作系统Windows 10 / 11 x64（推荐）；Linux x86_64 / aarch64；macOS Intel / Apple Silicon。三者都可运行 Java 版与 EasyTier 联机
Node.js20.19+ 或 22.12+
Ruststable，1.85+（项目使用 edition 2024）
桌面运行时Electron 内置 Chromium，不依赖 WebView2 或 WebKitGTK。
网络首次安装版本、依赖和 Java 需要联网
其他基岩版客户端需要 Windows 10 / 11；Linux 可运行官方 BDS 服务端（Ubuntu x86_64）；联机默认使用 IPv6 双向直连，需要双方公网 IPv6 并放行 TCP/UDP 11010；没有公网 IPv6 时可切换公益节点模式，由 EasyTier 协助节点打洞 / 中继
扩展 / 更新扩展不需要额外运行时；OTA 更新需要访问 GitHub Releases。扩展不是安全沙箱，只应安装可信来源。

平台说明Windows 支持 UWP / GDK / BDS、Xbox 运行时与防火墙集成；Linux 支持 Java 版、EasyTier 与 BDS（bin-linux）；macOS 支持 Java 版、EasyTier 与 MCPELauncher 客户端，不提供官方 BDS 与 Xbox 运行时。

03快速开始

从源码运行开发版，或者直接构建安装包。

bash
git clone https://github.com/Cerlesse-studio/Open-source-Minecraft-launcher.git
cd Open-source-Minecraft-launcher
npm ci
npm run start

Windows PowerShell如果提示「无法加载 npm.ps1，因为在此系统上禁止运行脚本」，改用 npm.cmd run start，或在 cmd 中执行 npm run start。

一键打包与 OTA 文件

一条命令完成安装包、OTA 元数据与校验文件：

bash
# 当前平台：安装包 + OTA 文件
npm run package

# 指定平台（必须在该系统上执行）
npm run package:win      # NSIS + 免安装版
npm run package:mac      # DMG + ZIP
npm run package:linux    # AppImage

# 只重建 latest.json / SHA256SUMS.txt
npm run package:ota

产物位于 release/v<版本>/，包含安装包、latest*.yml、latest.json 与 SHA256SUMS.txt。安装包会内嵌对应平台的 Rust 核心，因此三个系统需分别构建；将整个目录上传到同名 GitHub Release 即可供 OTA 更新使用。

测试

bash
# 前端类型检查 + 生产构建
npm run build

# 联机健康检查 / P2P 单元测试
npm test

# Rust 单元测试
cargo test --manifest-path src-tauri/Cargo.toml

# 可选：真实下载 / 启动冒烟测试
cargo run --manifest-path src-tauri/Cargo.toml --example smoke -- 1.8.9

04架构设计

整体分为四层：React 前端负责呈现，Electron IPC 负责通信，Rust 后端负责所有耗时与关键状态，外部服务提供版本、内容、账户与联机能力。

FRONTEND React 19 + TypeScript

页面、设置、主题、PCL2 主页、IPC 桥接

→
MAIN + BRIDGE Electron 主进程 + preload

窗口 · IPC · stdio 桥 · 更新器 · 登录窗口

↔
BACKEND Rust 2024

版本、下载、账户、基岩版、EasyTier、扩展解析

外部服务：Mojang / BMCLAPI / Betacraft · Modrinth / CurseForge / MC百科 · Microsoft / Xbox Live · EasyTier · GitHub Releases

设计取舍

  • 后端持有状态：安装与下载任务挂在 Rust 侧，切换页面不会中断；前端重新进入页面时读回真实进度。
  • 原子写入：下载先写 .part，校验 SHA-1 后再提交到目标路径；失败不会留下半成品文件。
  • 下载源透明：镜像失败会自动回退，用户不需要知道每个文件来自哪个源。
  • 账户令牌不经过前端：启动时会话由后端账户存储直接读取，减少令牌在 UI 层暴露的机会。
  • 进程隔离：Electron 主进程负责窗口、更新与 IPC，Rust 核心进程通过逐行 JSON stdio 通信；下载与启动逻辑不依赖渲染进程存活。
  • 可扩展但不假装沙箱：扩展在渲染进程执行，启动器会明确展示能力与风险；只安装可信扩展。

05下载引擎

下载引擎是启动器最核心的基础设施。版本核心、依赖、资源文件、模组、资源包与 EasyTier 内核都走同一套下载流程。

分片与自适应

文件 ≥ 1 MB 时按 HTTP Range 分片，每片至少 512 KB；线程档位 1–64 可调，分片并发实际上限 16 路。单文件小于 1 MB 仍走单线程。

场景处理方式
分片启动后 12 秒内低速不判失败，给镜像爬坡时间
12 秒后总吞吐持续 < 8 KB/s放弃分片，改用单连接继续下载
单个分片 30 秒收不到字节判定连接失效，重试或回退
镜像返回 429 / 503退避后逐个补齐剩余分片，避免整体失败
文件 < 1 MB直接单线程
分片 < 512 KB合并分片，避免过度切分

镜像容灾

候选地址覆盖官方 / 亚太 Anycast CDN、BMCLAPI、Forge / NeoForge / Fabric / Quilt Maven、Betacraft 旧版本资源、GitHub 加速镜像与 10 个 Xbox Live CDN 主机。遇到 404、超时或连接失败会自动换源；自定义镜像按 BMCLAPI 兼容路径重写，并校验必须为 http(s) 地址。

断点续传

任务通过 .part.meta 记录分片布局与完成情况，.part 不会在失败或换镜像时被删除。已下好的分片不会重复拉取；只有旁车文件与 .part 对不上时才自动重来。

为什么默认不是 64 线程？镜像对高并发连接很敏感。启动器会把实际分片并发限制在 16 路，并在吞吐过低时退回单连接，通常比盲目拉满线程更稳。

06账户体系

启动器同时支持微软账户与离线账户。微软登录采用 OAuth 2.0 设备码流程，不收集密码。

微软登录链路

  1. 向微软申请设备码，在浏览器中完成登录。
  2. 轮询令牌端点，拿到 Microsoft access token。
  3. 通过 Xbox Live 用户认证与 XSTS 授权。
  4. 调用 Minecraft Services 登录，获取 Java 会话。
  5. 读取 profile 与 entitlements，确认 Java / 基岩版授权。

刷新令牌保存在应用配置目录的 account.json；启动时由后端直接读取，不经过前端传输。Unix 平台会把文件权限设置为 0600。登录窗口只允许打开微软 / Xbox 官方域名。

离线账户

离线账户使用昵称与确定性 UUID，支持随机、Steve、Alex、Mojang 正版皮肤与本地自定义皮肤。自定义皮肤会打成 OfflineSkinPack 并写入 options.txt 的 resourcePacks；Mojang 皮肤通过官方签名纹理注入，1.19.2 及更早版本离线进入也能显示。

不要分享账户文件account.json 包含刷新令牌。提交 Issue 或分享日志时，请不要粘贴账户文件或任何令牌内容。

07扩展系统

0.1.4 新增扩展页面与运行时。扩展安装到同一个目录，可统一启用、停用、导出和卸载；目前支持启动器原生扩展与 Chrome Manifest V2 / V3 兼容扩展。

原生扩展JavaScript 后台脚本 + 可选 Rust/WASM 协处理器 + popup / tab UI。
Chrome 扩展读取 MV2 / MV3 的 popup、background、权限与 _locales 字段。
安装方式ZIP / CRX / 已解压目录；也支持生成内置示例扩展。
运行位置扩展脚本在启动器界面进程执行；Rust/WASM 负责计算型协处理。

目录与安装

扩展位于 <游戏目录>/extensions/，没有配置游戏目录时使用 ~/.cobble/extensions/。启用状态保存在 extensions.json，安装时会先写入临时目录再替换旧目录。

text
<游戏目录>/extensions/
├── extensions.json          # 启用状态
├── my-native-extension/     # 原生扩展
│   ├── manifest.json
│   ├── background.js
│   ├── plugin.wasm
│   └── popup.html
└── chrome-hello-world/      # Chrome 扩展
    ├── manifest.json
    ├── background.js
    ├── popup.html
    └── _locales/

Chrome API 子集

兼容层覆盖 chrome.storage.local/sync、chrome.runtime.id/getManifest/sendMessage/onMessage、chrome.notifications.create 与 chrome.i18n.getMessage 等常用能力。没有网页上下文，因此不提供 content script、tabs / windows、scripting、网络拦截或页面注入。

扩展不是安全沙箱后台脚本在启动器渲染进程中通过 new Function 执行，可访问 window、document 与启动器 API；.crx 只剥离容器头，不校验 Chrome 签名链。请只安装可信来源的扩展，权限字段仅作展示。

完整清单字段、Chrome 兼容范围、示例与限制见 扩展开发指南。

08多语言与自动更新

界面语言

界面支持简体中文（zh-CN）与 English（en-US）。语言设置保存在本机设置中，切换后立即生效；Minecraft 游戏内语言仍由版本设置单独控制。

OTA 更新

「设置 → 关于启动器 → 软件更新」会检查 GitHub Releases，比较版本并展示发布说明、更新包大小与下载进度。更新包缓存位于 Electron 用户数据目录的 updates/。

  • Windows 安装包 / NSIS 会启动安装程序；单文件免安装版会替换当前可执行文件并重新打开。
  • Linux AppImage 会在下载完成后替换当前 AppImage 并重启。
  • macOS 会打开 DMG，由用户完成安装。
  • 只接受由启动器从官方 Releases 下载的更新包路径，避免任意文件替换。

版本可能滞后当前仓库源码版本为 0.1.4，但 GitHub Releases 的安装包可能尚未同步到同一版本；需要最新功能时请从源码构建，或在更新器中查看 Releases 的实际版本。

09联机

联机以内置的 EasyTier v2.6.4 为内核，创建房间时可选择两种连接方式。

纯 IPv6 P2P（默认）房主分享码 + 访客回执码，双方直接向对方公网 IPv6 发包；不联系 STUN、信令或中继。
公益节点模式（可选）通过 EasyTier 协助节点打洞，必要时多线路中继；没有公网 IPv6 也能联机。

纯 IPv6 P2P：三步开房

  1. 装内核：双方进入「联机」页安装 EasyTier 内核。任务由后端持有，切页、重启启动器都可继续下载。
  2. 创建房间：保持「IPv6 直连（默认）」；进入游戏后点「对局域网开放」，启动器会从本次 logs/latest.log 自动读取端口并生成分享码。访客加入后把房间页的回执码发回房主，房主在「纯 IPv6 P2P」面板粘贴并点「登记」。
  3. 加入房间：好友粘贴整段分享码加入，打开游戏「多人游戏 → 局域网」即可看到世界；也可以手动直连房间页给出的 10.126.126.x:端口。

公益节点模式

切换到「公益节点模式」后，房主以 --no-listener 启动，不需要对外开放入站端口；双方通过 EasyTier 协助节点完成 P2P 打洞，无法直连时走多线路中继。节点选择支持：

  • 自动选择：按节点延迟测速结果自动优选，默认策略。
  • 手动指定：从节点卡片中固定一个协助节点。
  • 社区同步：从 info.qtet.cn 社区监控同步最新上线的中继节点。
  • 自建节点：添加自己的 EasyTier 节点并参与延迟检测。

纯 P2P 与公益节点模式不会自动互相切换；纯 P2P 失败时应明确选择公益节点模式，避免误以为仍在直连。

分享码与局域网发现

分享码格式为 cobble-mp://join?name=…&secret=…&peer=…&ip=…&port=…，访客回执码格式为 cobble-mp://reply?name=…&peer=…。纯 P2P 监听 tcp://[::]:11010 / udp://[::]:11010 并以 --p2p-only 运行；公益节点模式由协助节点与 --no-listener 路径处理。

点「显示到局域网」后，后端会在 127.0.0.1 上开一个 TCP 代理，并持续向 224.0.2.60:4445 与 127.0.0.1:4445 发送 [MOTD]…[/MOTD][AD]…[/AD]，好友的世界会直接出现在「多人游戏 → 局域网」里。

房间资源克隆

房间页会读取房主版本的资源清单，按模组、光影、数据包与资源包分组展示。访客可以勾选游戏版本、模组、光影与数据包，一键把房主环境克隆到本机对应实例；同名文件会被覆盖。版本差异是联机进不去世界最常见的原因之一，先克隆资源再连接通常更省事。

房间健康与断线

启动器会持续检查房间连接与房主状态。房主离开或网络断开时，访客会收到提示并退出无效房间，而不是停在一个永远连不上的页面；重新加入需要房主仍在线。

路由器限制启动器会自动放行 Windows 防火墙的本机 TCP/UDP 11010，不需要端口映射。但如果路由器的 IPv6 防火墙直接丢弃入站包，纯 P2P 仍会失败，软件无法远程修改路由器；此时需要在路由器 IPv6 防火墙放行 UDP 11010，或切换到公益节点模式。完整说明见 联机网络方案。

10基岩版

基岩版客户端面向 Windows 10 / 11，支持商店客户端、.msixvc GDK 加密包与 UWP / AppX 核心。Linux 走另一条路径：版本列表直接读取官方 bin-linux BDS 源，下载后保留可执行位并自动设置 LD_LIBRARY_PATH 启动服务端；macOS 没有官方运行时，只接管系统已安装的 MCPELauncher 客户端。

核心与依赖

所有基岩版启动路径都会在启动前自检运行依赖；Xbox GDK 路径会通过 winget 自动补齐「Xbox 应用」与「游戏服务」。UWP / AppX 核心由启动器自行解包，并以开发模式注册，不经过 Microsoft Store。

集成 90+ 条官方 Xbox Live CDN 直链，覆盖正式版与预览版；基岩版下载源可在 McAppx 官方源、BedrockBoot Gitee 源、BMCBL、EndstoneMC 社区源与 Azure CDN 镜像之间切换。Linux BDS 读取 Mojang 官方 bin-linux，当前仅覆盖 Ubuntu x86_64。

附加包与存档

原生支持 .mcpack / .mcaddon / .mcworld。安装时读取包内 manifest.json，按模块类型分区解压；.mcaddon 内嵌的 .mcpack 会递归安装，.mcworld 通过 level.dat 识别并导入 minecraftWorlds。安装结果会写入所有已存在的游戏数据目录。

附加包管理器会扫描所有已存在的 com.mojang 数据目录，按资源包、行为包、皮肤包、世界模板分组，支持启停、批量操作、删除与本地导入。停用会把包移动到同目录的 cobble_disabled_packs。

加载器与 DLL 模组

  • LeviLamina：接入官方 levilamina-client-version-db，匹配并部署对应版本。
  • Amethyst：原生 C++ 客户端 Mod 注入框架。
  • DllMods：支持原生 .dll 模组、LeviLamina 插件与行为包的一键启停（.disabled 切换）、删除与本地导入。

12数据目录

默认游戏目录为 ~/.cobble（Windows 下通常是 C:\Users\<用户名>\.cobble），可以在设置中修改。

│       └── logs/
├── saves/                   # 共享 Java 存档与从内容市场安装的地图
├── resourcepacks/           # 共享资源包
├── shaderpacks/
├── datapacks/
├── modpacks/                # 从内容市场下载的整合包
├── extensions/              # 扩展与 extensions.json
├── runtime/                 # 自动下载的 Temurin JRE
│   └── temurin-<major>/
├── easytier/                # EasyTier 内核、安装状态与断点

账户文件不在游戏目录里，而是位于应用配置目录（Windows 通常为 %APPDATA%\com.opensource.minecraft.launcher\account.json），因此切换游戏目录不会退出登录。OTA 更新缓存位于 Electron 用户数据目录的 updates/，同样不在游戏目录内。

备份建议复制整个游戏目录即可备份存档、模组、资源包与游戏内配置；启动器设置与账户在应用自己的数据目录，建议单独备份 account.json。

13构建与测试

日常开发、构建与测试命令如下。提交 PR 前建议至少运行前端构建与 Rust 测试。

bash
# 前端类型检查 + 生产构建
npm run build

# 联机健康检查 / P2P 单元测试
npm test

# Rust 单测
cargo test --manifest-path src-tauri/Cargo.toml

# 当前平台：安装包 + OTA 文件
npm run package

# Windows NSIS + 免安装版 / macOS DMG + ZIP / Linux AppImage
npm run package:win
npm run package:mac
npm run package:linux

# 可选的下载 / 启动冒烟测试（会真实下载并尝试启动游戏）
cargo run --manifest-path src-tauri/Cargo.toml --example smoke -- 1.8.9

构建产物位于 release/v<版本>/，包含带版本号的安装包、标准 latest*.yml、汇总清单 latest.json 与 SHA256SUMS.txt。Windows 生成 NSIS 与免安装版，macOS 生成 DMG 与 ZIP，Linux 生成 AppImage；首次构建会编译全部 Rust 依赖，耗时会明显更长。

格式化cargo fmt --manifest-path src-tauri/Cargo.toml -- --check
静态检查cargo clippy --manifest-path src-tauri/Cargo.toml --all-targets -- -D warnings

14常见问题

需要正版账号吗？

不强制。离线账户可以启动单人与离线服务器；微软账户登录后可获得正版 Java 会话、皮肤与基岩版授权检测。启动器不会要求输入微软密码，登录在微软官方页面完成。

没有安装 Java，或者 Java 版本不匹配怎么办？

启动器会按版本元数据匹配 Java 主版本；找不到时自动下载 Temurin JRE 到 <游戏目录>/runtime/。也可以在「设置 → 游戏与启动」或版本设置里手动指定 Java。

基岩版一定要安装 Microsoft Store 吗？

不必须。启动器支持 UWP / AppX 以开发模式注册、.msixvc GDK 核心与 BDS 独立核心；商店客户端只是其中一种来源。GDK 路径会通过 winget 补齐 Xbox 应用与游戏服务。Linux x86_64 可直接从版本列表安装 Mojang 官方 bin-linux BDS，无需商店或 Xbox 运行时；macOS 没有官方运行时，只接管系统已安装的 MCPELauncher 客户端。

联机需要公网 IPv6 吗？

默认的 IPv6 双向直连需要双方都有公网 IPv6，并放行本机 TCP/UDP 11010。启动器不联系 STUN、信令或中继；路由器通常不需要端口映射，但如果其 IPv6 防火墙直接丢弃入站包，仍需在路由器放行或改用自建中继。没有公网 IPv6 时，可在创建页切换到公益节点或自建中继模式。

扩展安全吗？

扩展在启动器渲染进程中执行 JavaScript，不是浏览器级沙箱，并且 .crx 不会校验 Chrome 签名链。请只安装可信来源的扩展；Chrome 扩展只支持 popup、background、storage、runtime 消息、notifications 与 i18n 等子集，不提供 content script、tabs、网络拦截或页面注入。

如何更新启动器？

在「设置 → 关于启动器 → 软件更新」中检查 GitHub Releases。Windows 单文件 / NSIS 与 Linux AppImage 可以自动替换并重新打开，macOS 会打开 DMG 由用户完成安装。当前源码版本为 0.1.4，Releases 安装包可能滞后。

下载慢、镜像 404 或经常中断怎么办？

先在「设置 → 下载与网络」里测速并切换到更快的源，线程数建议 8–16。镜像对高并发限速时，启动器会自动退回单连接；大文件支持断点续传。遇到 404 会自动尝试备用镜像。

启动失败怎么排查？

先看主页 / 版本设置里的实时日志，确认 Java 主版本、游戏目录权限、版本隔离与模组冲突；旧版本注意 LegacyFix 相关参数。仍然无法解决时，请附上日志、系统信息和复现步骤提 Issue，不要粘贴账户令牌。
